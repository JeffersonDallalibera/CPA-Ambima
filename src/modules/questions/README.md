# Questions Module (`src/modules/questions`)

## Ownership
- **View**: `#view-questoes`
- **Capabilities**:
  - 148 Commented Questions (121 Official Cesgranrio / ANBIMA Edu + 27 Inéditas)
  - Option-by-option A, B, C, D justification engine
  - Strikethrough eliminator (`✂️`) & Question Navigator Map
  - Filters: Module, Origin (Oficial / Inédita / Caderno de Erros / Favoritas), Difficulty & Search
- **Data Dependencies**:
  - `POST /api/questions/answer`
  - `POST /api/questions/favorite`
