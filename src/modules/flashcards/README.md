# Flashcards Module (`src/modules/flashcards`)

## Ownership
- **View**: `#view-flashcards`
- **Capabilities**:
  - 78 3D Active Recall Flashcards across Modules 1, 2, 3, and 4
  - 60fps CSS `transform: rotateY(180deg)` 3D card flip
  - Keyboard shortcuts (`Space` to flip, `ArrowLeft` / `ArrowRight` to navigate)
